# نطاق MVP لمنصة SENSE

## الغرض

يحدد هذا المستند ما يمكن عرضه واختباره في نسخة SENSE الحالية، وما يبقى مشروطًا بتفعيل خارجي أو بمصدر بيانات موثق. لا تُعامل أي ميزة غير موصولة بمصدر حقيقة أو إجراء خادم محمي على أنها مكتملة.

## مسارات تعمل في النسخة الحالية

| المسار | الحالة التشغيلية | مصدر الحقيقة أو القيد |
|---|---|---|
| الزائر العام | صفحات عربية RTL للسياحة والخدمات والسوق المحلي والمتجر والمعلومات | محتوى المنصة والكتالوج المنشور فقط |
| المواطن | إنشاء البلاغ، متابعة بلاغاته، رفع صور عبر S3، تقييم بعد الإغلاق، الإشعارات | قاعدة بيانات SENSE وS3؛ لا تُعرض بيانات غير موثقة |
| التشغيل | طوابير الموظف والميداني والمشرف والمدير، انتقالات حالة مقيدة، خريطة البلاغات القريبة، مؤشرات مفلترة | صلاحيات الخادم وسجل الأحداث |
| المزود | الملف، الأعضاء، المنتجات والخدمات، المراجعة الإدارية، النشر بعد الاعتماد، الأرشفة الناعمة | كتالوج المزودين وقواعد الملكية |
| المتجر | كتالوج Shopify، بحث وفلاتر مبنية على productType/tags، سلة، إحالة Checkout | Shopify Storefront؛ حالة الدفع والشحن خارجية حتى يثبت مصدر Admin/Webhook |
| الوصول | RTL، تكبير وتصغير النص، تباين، تقليل الحركة، قراءة عربية اختيارية، تفضيلات محلية | إعدادات المستخدم على جهازه؛ لا تُعد بديلًا عن اختبار قارئ شاشة متخصص |

## مسارات غير مكتملة أو مشروطة

تظل سجلات الطلبات وحالات الدفع والشحن، وإشعارات الطلبات، ومساعد الموظف، ودليل الوجهات الموثق، والتطبيقات المنفصلة، وتكامل Shopify Admin/Webhook، وتدقيق قارئ الشاشة الكامل، عناصر غير مكتملة أو مشروطة بمصدر خارجي أو اختبار متخصص.

## قاعدة العرض والنشر

يُعرض المحتوى المنشور فقط عندما يكون معتمدًا أو قادمًا من Shopify. لا يجوز إنشاء مراجعات أو تقييمات أو شهادات عملاء وهمية. النشر النهائي يتم من واجهة المشروع بعد مراجعة الأسرار، نطاقات OAuth، اتصال قاعدة البيانات، وملكية المتجر.

## معايير القبول

تُعتبر الميزة قابلة للعرض عندما تمر typecheck والاختبارات والبناء، وتملك حالة تحميل وفراغ وخطأ، وتستخدم حماية خادم مناسبة، وتظهر في مسار يمكن الوصول إليه من التنقل، ويكون مصدر بياناتها معروفًا ومذكورًا في الوثائق.
