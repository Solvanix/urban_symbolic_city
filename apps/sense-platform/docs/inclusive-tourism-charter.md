# ميثاق السياحة الشاملة في SENSE

SENSE منصة عربية أولًا للسياحة والخدمات الحضرية الشاملة. يبدأ تصميم التجربة من احتياجات الوصول التي يختارها المستخدم، لا من افتراضات عن الإعاقة أو العمر أو المرافق. هدف المنصة هو تمكين الزائر من اكتشاف خدمة أو وجهة، فهم مستوى الوصول الموثق، بناء مسار قابل للتعديل، ثم الإبلاغ عن العوائق ومتابعة المعالجة عبر دورة مدنية قابلة للتدقيق.

## مبادئ المنتج

| المبدأ | التطبيق في SENSE |
|---|---|
| الاختيار والتحكم | ملف تفضيلات محلي قابل للحفظ والمسح، ولا تُرسل التفضيلات للخدمات الخارجية دون حاجة واضحة |
| معلومات وصول موثقة | لا تُعرض معلومة وصول كحقيقة نهائية دون مصدر أو تاريخ تحقق واضح |
| بدائل متعددة | تكبير النص، التباين، تقليل الحركة، القراءة الصوتية، RTL، ومسارات بديلة عند تعذر الخريطة أو الصوت |
| كرامة المستخدم | لغة غير وصمية، وعدم تخمين الاحتياج أو نشر بيانات حساسة |
| القرار البشري | اقتراحات الذكاء الاصطناعي غير ملزمة، والقرارات التشغيلية والإدارية بيد البشر |
| أثر قابل للقياس | ربط البلاغات والإغلاق والتقييمات بمؤشرات حقيقية، دون أرقام تجميلية أو مراجعات وهمية |

## حدود الميثاق

لا يثبت هذا الميثاق أن كل وجهة أو مزود خدمة متاح بالكامل. إثبات الإتاحة يتطلب بيانات موثقة ومؤرخة واختبارًا ميدانيًا مناسبًا، وستظل العناصر غير المتحققة معلّمة للمستخدم بدل تقديم ضمانات عامة.
