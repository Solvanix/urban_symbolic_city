# مواصفة دليل الوجهات الموثقة

## الغرض

لا يعرض دليل SENSE أي وجهة على أنها مهيأة أو متاحة قبل إدخال سجل قابل للمراجعة. الصفحات العامة تعرض حالة فارغة عندما لا تتوفر سجلات مستوفية؛ وهذا مقصود لحماية الزائر من الادعاءات العامة أو المعلومات القديمة.

## الحقول الإلزامية

| الحقل | المتطلب | قاعدة العرض |
|---|---|---|
| `id` | معرف ثابت للوجهة | لا يتغير عند تحديث البيانات |
| `name` | الاسم الرسمي كما يظهر لدى الجهة المالكة | لا تستخدم أسماء تسويقية غير قابلة للتحقق |
| `type` | فئة الوجهة | قيمة من قاموس فئات معتمد |
| `note` | وصف واقعي ومحدد لخصائص الوصول | لا يستنتج من اسم الوجهة أو تقييمات عامة |
| `tags` | خصائص وصول قابلة للإثبات | كل وسم يجب أن يرتبط بمصدر |
| `verifiedAt` | تاريخ آخر تحقق بصيغة UTC | تنتهي الصلاحية وفق سياسة المراجعة |
| `sourceUrl` | رابط عام إلى المصدر الأصلي | يجب أن يفتح دون حساب خاص متى أمكن |
| `verifier` | اسم الجهة أو الموظف الذي راجع السجل | لا يكفي اسم المنصة وحده |
| `evidenceType` | نوع الدليل: زيارة ميدانية، جهة رسمية، مخطط منشور، أو إفادة مزود | يمنع تحويل الرأي إلى حقيقة |
| `reviewDueAt` | موعد المراجعة التالية | لا يعرض السجل بعد تجاوزه دون تنبيه أو إعادة تحقق |

## هرم المصادر

تُرتب الأدلة حسب القوة: مصدر رسمي من مالك المرفق أو البلدية، ثم تقرير زيارة ميدانية مؤرخ من فريق مؤهل، ثم مستند تشغيلي منشور من المزود. لا يُستخدم محتوى المستخدمين أو الصور المنفردة لإثبات خاصية وصول دون مراجعة مستقلة.

## سياسة العرض

يجب أن تعرض بطاقة الوجهة تاريخ التحقق ورابط المصدر وعبارة توضح أن الخصائص قد تتغير. إذا غاب أي حقل إلزامي، أو انتهت المراجعة، أو تعارضت الأدلة، يُحجب السجل من الدليل العام وتُعاد حالته إلى المراجعة. لا تُنشأ سجلات تجريبية أو أسماء وجهات افتراضية في الإنتاج.

## مسار الإدخال والاعتماد

يُدخل المزود أو الجهة المالكة السجل، ثم يراجعه موظف مخول، ثم يُنشر بعد نجاح فحوص الحقول والرابط والتاريخ. يسجل النظام هوية المراجع ووقت القرار وتاريخ انتهاء الصلاحية. أي تعديل جوهري على المسار أو المدخل أو المصاعد يعيد السجل إلى المراجعة.

## حدود MVP الحالية

لا توجد وجهات موثقة منشورة في الكتالوج الحالي. لذلك تعرض `/tourism` حالة شفافة بلا بطاقات وجهات، بينما تبقى مسارات البلاغات ومخطط الرحلة متاحة دون تحويلها إلى شهادة وصول. يمكن تفعيل الدليل عند وصول بيانات فعلية تستوفي هذه المواصفة.
