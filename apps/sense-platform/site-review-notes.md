# مراجعة المواقع الحالية

## متجر SENSE

المصدر: https://sense.runasp.net/

العنوان الظاهر: Sense Store.

الانطباع العام: متجر قائم وقابل للتصفح، وليس مجرد صفحة تعريفية. يضم بحثًا عن الفئات، المفضلة، السلة، تسجيل الدخول، تصفح الفئات، وصفحات رئيسية ومن نحن والأقسام والفروع والانضمام كمزوّد منتج أو خدمة وطلباتي وحسابي.

المحتوى الظاهر يركز على المنتجات الأصيلة المصنوعة بأيدٍ فلسطينية، التراث والحضارة، تمكين الحرفيين والمبدعين المحليين، التوصيل، الدفع الآمن، والدعم المحلي. توجد فئات واسعة جدًا تشمل الحرف والتراث، الأغذية، المطاعم، الإلكترونيات، الأزياء، المنزل، الصحة، السفر، وغيرها.

ملاحظات معمارية وتجريبية أولية: المتجر يحتوي على قيمة ومحتوى وكتالوج وفئات ومسارات مستخدم يمكن الاستفادة منها. توجد مؤشرات على متجر متعدد الفئات وربما متعدد الموردين. الواجهة الحالية تبدو مستقلة عن منصة SENSE الحضرية المقترحة، لذلك لا ينبغي نسخ محتوى المتجر أو إنشاء كتالوج بديل قبل تحديد مصدر الحقيقة للمنتجات والطلبات والمورّدين.

المسار الموصى به مبدئيًا: إعادة استخدام المتجر كمصدر بيانات وتجربة تجارية قائمة إن كان يملك API أو قاعدة بيانات قابلة للتكامل، أو إعادة تصميم واجهته فقط داخل مظلة SENSE مع إبقاء نظام المنتجات والطلبات الأصلي خلف طبقة تكامل. لا يُحسم هذا قبل فحص التقنية وواجهات التكامل والملكية.

## موقع الفريق Senseivo

المصدر: https://www.senseivo.com/

العنوان الظاهر: Senseivo — استوديو رقمي.

الانطباع العام: موقع تعريفي احترافي نسبيًا لفريق/استوديو رقمي، ويحتوي على هوية واضحة ورسالة تسويقية متماسكة، مع تنقل للرئيسية وفلسفتنا وخدماتنا وأعمالنا ومعرض المنتجات وتواصل معنا، وزر حجز استشارة وتحويل للغة الإنجليزية.

الرسالة الأساسية: دمج ذكاء التصميم بصلابة البرمجة، وبناء أصول رقمية مستدامة قابلة للتوسع. الخدمات المعروضة تشمل UI/UX، التطوير البرمجي الكامل، استراتيجية وتطوير المنتجات، وتكامل الأنظمة وبوابات الدفع.

المحتوى يضم معرض أعمال، صفحة مشاريع، أسئلة شائعة، ونموذج تواصل يحتوي الاسم والبريد والموضوع والرسالة، إضافة إلى بيانات اتصال الهاتف والبريد. توجد إشارات إلى مشروع متجر خدمات متعدد البائعين، لكن الموقع نفسه يبدو موقع الفريق/الاستوديو وليس لوحة تشغيل للمنصة البلدية أو المتجر.

ملاحظات معمارية وتجريبية أولية: هذا الموقع يجب الحفاظ عليه كواجهة هوية وثقة واستوديو، لا دمجه قسرًا داخل لوحة SENSE التشغيلية. الأنسب ربطه عبر هوية بصرية وروابط واضحة إلى SENSE، وصفحة حالة/دراسة حالة للمنصة، وربما نطاقات فرعية أو مسارات مستقلة. إعادة بناء الموقع داخل مشروع SENSE قد تكون مفيدة فقط إذا كان الهدف توحيد الإدارة والنشر، أما من ناحية المنتج فالفصل بين موقع الفريق والمنصة أفضل.

## مراجع السياحة الشاملة والوصول الرقمي

تمت مراجعة معيار W3C WCAG 2.2 الرسمي. يركز المعيار على جعل المحتوى قابلًا للإدراك والتشغيل والفهم والمتانة، ويشمل بدلالة مباشرة للمنصة: بدائل نصية للمحتوى غير النصي، أسماء واضحة لعناصر التحكم، دعم لوحة المفاتيح، عدم حبس المستخدم داخل المكونات، قابلية تغيير الوقت، التباين، تكبير النص وإعادة التدفق، وعدم الاعتماد على اللون وحده. المصدر: https://www.w3.org/TR/WCAG22/

تمت محاولة فتح إرشادات UN Tourism حول السياحة المتاحة، لكن الصفحة واجهت CAPTCHA. نتيجة البحث تشير إلى أن الإرشادات موجهة لمساعدة أصحاب المصلحة السياحيين على تحسين إتاحة الوجهات والمنشآت والخدمات عالميًا، وهو ما يدعم قرار بناء المنصة كمنظومة قيمة كاملة تشمل الوجهة ومزود الخدمة والمنتج والنقل والمرافقة، لا كواجهة وصول رقمية فقط. المصدر: https://www.untourism.int/accessibility-tourism-publications-guidelines

قرار تصميمي أولي: سيكون WCAG 2.2 AA خط أساس للواجهة الرقمية، مع نموذج بيانات سياحي يميز بين معلومات الوصول الموثقة، معلومات غير مكتملة، وتحقق ميداني/زمني؛ لأن المنصة لا ينبغي أن تصنع ادعاءات وصول غير مثبتة.
